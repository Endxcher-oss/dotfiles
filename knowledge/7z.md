# 7z CLI 使用说明

## 基本语法

```
7z <命令> [选项] <压缩包名> [文件...]
```

## 常用命令

| 命令 | 说明 |
|------|------|
| `a` | 添加文件到压缩包（创建） |
| `x` | 解压（保留完整路径） |
| `e` | 解压（所有文件到同一目录，忽略路径） |
| `l` | 列出压缩包内容 |
| `t` | 测试压缩包完整性 |
| `d` | 从压缩包删除文件 |
| `u` | 更新压缩包中已存在的文件 |
| `rn` | 重命名压缩包内的文件 |
| `h` | 计算文件的哈希值 |
| `i` | 显示支持的格式信息 |
| `b` | 基准测试 |

## 常用示例

```bash
# 压缩（创建）
7z a archive.7z file1.txt dir1/

# 压缩为 zip 格式
7z a -tzip archive.zip file1.txt

# 解压到当前目录（保留路径）
7z x archive.7z

# 解压到指定目录
7z x archive.7z -o/tmp/out

# 解压（所有文件平铺到一个目录）
7z e archive.7z

# 查看内容
7z l archive.7z

# 测试完整性
7z t archive.7z

# 删除压缩包内的文件
7z d archive.7z file1.txt

# 更新文件
7z u archive.7z file1.txt

# 计算哈希
7z h file1.txt
```

## 常用选项

| 选项 | 说明 |
|------|------|
| `-t<格式>` | 指定格式：`7z`、`zip`、`tar`、`gzip`、`bzip2` 等 |
| `-p<密码>` | 设置密码（`-p` 不带参数则交互式输入） |
| `-o<目录>` | 指定解压输出目录（紧跟 `-o`，无空格） |
| `-r` | 递归处理子目录 |
| `-y` | 所有询问自动回答"是" |
| `-mx=N` | 压缩级别：`0`(仅存储) ~ `9`(最大压缩) |
| `-mhe` | 加密文件头（仅 7z 格式） |
| `-sdel` | 压缩后删除源文件 |
| `-v<大小>` | 分卷压缩，如 `-v100m`、`-v10m` |
| `-x@<文件>` | 使用排除列表文件 |

## 实用组合

```bash
# 加密压缩（含文件头加密）
7z a -p密码 -mhe archive.7z secret.txt

# 分卷压缩（每卷 100MB）
7z a -v100m big.7z bigfile.iso

# 最大压缩
7z a -mx=9 -t7z archive.7z dir/

# 解压加密分卷包（第一分卷）
7z x archive.7z.001 -p密码

# 递归压缩目录下所有文件
7z a -r archive.7z dir/

# 压缩后删除源文件
7z a -sdel archive.7z *.log
```

## 注意事项

- 解压目录选项 `-o` 后**不能有空格**：`-o/tmp/out` ✓，`-o /tmp/out` ✗
- 分卷包解压时指定**第一个分卷**（`archive.7z.001`）
- 加密包解密时需在解压命令中提供 `-p` 密码
